# Ürün Gereksinimleri Dokümanı — Sayac Test Uygulaması ## 1. Genel Bakış Sayac Test Uygulaması, kullanıcıların artırma, azaltma ve sıfırlama işlemleriyle sayac değerini yönetmelerini sağlayan minimal ama işlevsel bir web uygulamasıdır. ## 2. Hedefler 1. Sayaç yönetimi (artır, azalt, sıfırla). 2. Zaman damgalı geçmiş (son 10 işlem). 3. Koyu/açık tema desteği (localStorage). 4. Türkçe arayüz. 5. Responsive tasarım. ## 3. Tech Stack - React 18.3, Vite, Tailwind CSS, TypeScript, Lucide React. ## 4. Fonksiyonel Gereksinimler - Sayaç: +/- 999.999.999 aralığı. - Kısayollar: +, -, R, D. - Onay mekanizması: Sıfırlama işlemi için modal. ## 6. UI/UX Gereksinimleri - Stil: Minimal, temiz. - Renkler: Primary (#3B82F6), Background (#111827), Surface (#1F2937). - Tipografi: Inter (Heading/Body), JetBrains Mono (Zaman). ## 10. Ekranlar 1. Ana Sayfa (Sayaç, butonlar, geçmiş). 2. Sıfırla Onay Modalı. 3. Taşma Uyarı Toast (Max/Min limit). 4. Boş Geçmiş Durumu. 5. Klavye Kısayolları Paneli.
